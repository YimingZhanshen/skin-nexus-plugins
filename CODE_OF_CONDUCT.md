# Code of Conduct

## Our pledge

Participants in the SkinNexus plugin repository — contributors, reviewers and
maintainers — pledge to make participation harassment-free regardless of
experience, identity, appearance, language, location or technical preference.

## Expected behavior

- Critique code and designs, not people; assume good faith.
- Respect different deployment environments and downstream forks.
- Provide verifiable information: reproduction steps, logs, real command output.
- Keep privacy intact: never publish real names, domains, IPs, emails or user data.
- Accept maintainer decisions grounded in [`SPEC.md`](SPEC.md) and
  [`REVIEW.md`](REVIEW.md).

## Unacceptable behavior

- Insults, discriminatory remarks, or attacks based on identity.
- Harassment, stalking, threats, sexualized content, or doxxing.
- Posting keys, tokens, user data or unredacted production logs in issues/PRs.
- Malicious contributions: backdoors, hidden telemetry, supply-chain attacks,
  attempts to bypass the plugin sandbox, route tiers or signature checks.
- Sustained disruption of discussions or repeatedly reopening closed issues.

## Scope

This code applies to issues, pull requests, reviews and discussions in this
repository, and to public interactions made on behalf of the project
(including the signed market and plugin collaboration).

## Reporting

- Preferred: contact the maintainer privately via GitHub
  [@YimingZhanshen](https://github.com/YimingZhanshen).
- If private contact is not possible, open an issue that only says
  "request for a private conduct channel" — **do not include incident details**.
- For threats or severe abuse, use GitHub's Report abuse feature.
- Reports are handled confidentially; the maintainer recuses themselves if the
  report concerns them, and a neutral third party handles it.

## Enforcement

Maintainers may remove, edit or reject content and contributions that violate
this code, and may temporarily or permanently restrict participation:

1. private reminder and request to correct;
2. warning with explicit boundaries;
3. temporary restriction (issue/PR access, collaboration paused);
4. permanent ban.

Severe incidents (threats, doxxing, deliberate sabotage) may skip to step 3 or 4.
